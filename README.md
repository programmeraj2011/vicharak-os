# 🧠 Vicharak OS

> **The Future of Computing, Right Inside Your Browser.**

Vicharak OS is a futuristic browser-based operating system built entirely with **HTML, CSS, and Vanilla JavaScript**. It recreates the desktop experience with draggable windows, built-in applications, a modern UI, and an AI-inspired workspace—all without any frameworks.

---

## ✨ Features

* 🖥️ Desktop-style interface
* 🪟 Draggable & resizable windows
* 🚀 Animated boot screen
* 📂 File Explorer
* 📝 Notes App
* 💻 Terminal
* 🌐 Browser
* 🧮 Calculator
* 📅 Calendar
* 🎵 Music Player
* ⚙️ Settings
* 🔔 Notification Center
* 🔍 Spotlight-style Search
* 🌙 Dark & Light Themes
* 🎨 Wallpaper Customization
* 💾 LocalStorage-based persistence
* 📱 Responsive Design
* ⚡ Smooth animations and transitions

---

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* LocalStorage API
* Web Speech API *(planned)*
* Web Audio API *(planned)*

No frameworks. No libraries. Just the web.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/vicharak-os.git
```

Open the project folder and launch `index.html` in your browser.

No installation or build tools required.
